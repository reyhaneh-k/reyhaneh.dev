## About

This is the source for **[reyhaneh.dev](https://reyhaneh.dev)** — my personal portfolio and professional home on the web.

It's where I showcase who I am as a **frontend / software engineer**: fintech & web work, writing (The 16ms Club, JS Daily Bite), and the craft behind shipping products that feel fast, polished, and intentional.

Built with a performance-first mindset — because if you're in **The 16ms Club**, your own site should practice what you preach.

## Features

- **About & experience** — career story, roles, and what I'm building now

## Getting started



### Prerequisites

- **Node.js** 20+
- **pnpm**, **npm**, or **yarn**



### Install & run

```bash
git clone https://github.com/reyhaneh-k/reyhaneh.dev.git
cd reyhaneh.dev
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Scripts


| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Start development server |
| `npm run build` | Production build         |
| `npm run start` | Serve production build   |
| `npm run lint`  | Run ESLint               |


> Scripts assume a Next.js setup. Update this table if the stack changes during scaffolding.
